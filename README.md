# Reverse an Array Using Pointers in C
## Description
 This program reverses the order of the elements in an integer array using two pointers, without creating a second array.

## Objectives

* Understand pointers in C.
* Traverse an array using pointers.
* Swap array elements using a temporary variable.
* Use functions and loops.

## Example

Input:

Array: 2 5 8 10 15

Output:

Original array: 2 5 8 10 15
Reversed array: 15 10 8 5 2
